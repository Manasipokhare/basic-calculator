🔹 Project Description
This project is a Basic Calculator built using HTML, CSS, and JavaScript. It performs arithmetic operations such as addition, subtraction, multiplication, and division. The goal is to practice front-end development skills and strengthen understanding of core web technologies.

🔹 Features
User-friendly interface with a display for input and results.

Buttons for digits (0–9), decimal point, and operators (+, −, ×, ÷).

Special buttons for Clear (C) and Equals (=).

Supports both button clicks and keyboard input.

Handles errors gracefully (e.g., division by zero).

Follows correct order of operations (BODMAS).

🔹 How to Run Locally
Clone the repository:

bash
git clone https://github.com/Manasipokhare/basic-calculator.git
Open the project folder in VS Code.

Install the Live Server extension in VS Code.

Right-click index.html → Open with Live Server.

The calculator will open in your browser at http://localhost:5500.
